# bigDataStack Data Engineer Journey

This repository tracks my progress through the **Data Engineer** profession path from [bigDataStack](https://bigdatastack.dev/profesion/ingenieria-datos), covering the **Training** section: lessons, sub-lessons, theory, and hands-on practice.

The **Real World** section will be addressed later, once its structure and project distribution are defined.

## Repository Structure

Each lesson lives in its own branch, with a corresponding folder holding its sub-lessons (theory and practice). This keeps the repo shallow and avoids deeply nested folder levels.

Example:

```
git branch: 03/logical-thinking-and-programming
- folder: 06-mini-project

git branch: 04/python-from-scratch
- folder: 02-installing-python
- folder: 03-list-and-dictionaries
```

## How to Navigate

Each lesson lives in its own branch. To explore a specific lesson, check out its branch:

```bash
git checkout 03/logical-thinking-and-programming
```

Inside each branch you'll find a folder per lesson, with sub-lessons split into `theory` and `practice`.
